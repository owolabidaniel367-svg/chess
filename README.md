# JavaScript Chess Game

A fully functional chess game built with HTML, CSS, and JavaScript.

## Features

- Legal chess moves
- Check detection
- Checkmate system
- Castling
- Pawn promotion
- Chess timers
- Captured piece display

## Technologies Used

- HTML
- CSS
- JavaScript

## How To Run

1. Download the project
2. Open `index.html`
3. Start playing

## Controls

- Click a piece to see legal moves
- Click a highlighted square to move
- Promote pawns by selecting a piece
